## Open questions

These are unresolved, and each one needs evidence rather than a decision:

1. **Does a real VLM see these checkpoints?** The reference procedure assumes a
   model can tell a resistor bridging two rows from an empty row. Untested
   against real footage — this is the first thing to measure with credentials.
2. **Is whole-frame absence reliable enough?** `absent` currently means "the
   model says the area was visible and empty". Letting an expert mark the
   checkpoint region on a frame would make that far stronger.
3. **How much overlap is right?** 4-second windows with 1 second of overlap is a
   guess that works for the fixtures. Real footage may want more overlap and a
   stricter independence gap.
4. **Should a correction continue an attempt or start a new one?** KIFACH
   currently handles a correction inside one attempt. A second attempt after a
   failure is a separate record, with no link between them yet.
5. **What does a learner see over time?** There is no cohort or history view;
   attempts are listed per skill and nothing is aggregated.
