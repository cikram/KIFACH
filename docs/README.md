## Product brief

**KIFACH — "Show once. Teach forever."** An expert records a short physical
demonstration. KIFACH identifies observable actions, builds a procedure that the
expert reviews and publishes, observes a learner's attempt, and explains
completion or mistakes with time-linked evidence. The demo loop is
**teach → review procedure → attempt → inspect feedback → correct**.

The hackathon is GOMYCODE "Come Build with AI" in Morocco, in partnership with
NVIDIA. The build window is 11 hours. One reliable, visual, short physical task
beats breadth.

## The shape, as built

Expert media → timestamped observations → a draft procedure with steps,
checkpoints, and dependencies → **expert review and publication** → learner media
→ timestamped observations → a deterministic engine → a verdict with evidence.

The demo task is the LED circuit: seat the LED, fit the current-limiting
resistor, connect ground, apply power, confirm it lights. The reviewed safety
rule is resistor before power. Uploaded recordings are the primary path; live
camera capture runs the same pipeline with stricter confirmation. See
[`brain/decisions.md`](brain/decisions.md) for why each of these was chosen.

## Open questions

These are unresolved, and each needs evidence rather than a decision:

1. **Does a real VLM see these checkpoints?** The reference procedure assumes a
   model can tell a resistor bridging two rows from an empty row. Untested
   against real footage — the first thing to measure once credentials exist.
2. **Is whole-frame absence reliable enough?** `absent` currently means "the
   model says the area was visible and empty". Letting an expert mark the
   checkpoint region on a frame would make that far stronger.
3. **How much overlap is right?** Four-second windows with one second of overlap
   works for the fixtures. Real footage may want more overlap and a stricter
   independence gap.
4. **Should a correction continue an attempt or start a new one?** KIFACH
   handles a correction inside one attempt today; a later attempt is a separate
   record with no link between them.
5. **What does a learner see over time?** There is no cohort or history view;
   attempts are listed per skill and nothing is aggregated.
