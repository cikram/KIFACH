# KIFACH

Turn one expert demonstration into a reviewable procedure, then assess a learner's attempt with evidence.

## Run

The frontend starts as a blank React shell:

```sh
cd frontend
npm install
npm run dev
```

The Python backend has empty function stubs and no server or run command yet. Add its exact command when the first working slice is built.

Start with [the project brief](docs/brain/README.md) and [source layout](docs/brain/components.md).
